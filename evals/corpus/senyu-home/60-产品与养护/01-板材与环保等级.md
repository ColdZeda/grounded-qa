# 板材与环保等级

> 本页自 2026-01-01 起生效，**现行有效**。适用于柜类、桌类、床架等含人造板的商品。

## 我们用什么板

| 材质 | 用在哪 | 特点 |
|---|---|---|
| **实木**（橡木、白蜡木、橡胶木） | 床架、桌面、椅腿 | 有天然纹理与色差，会随湿度轻微形变 |
| **多层实木板**（胶合板） | 柜体、层板 | 抗变形好，握钉力强 |
| **颗粒板**（刨花板） | 衣柜柜体、抽屉 | 成本低，**怕水**，封边一旦破损易膨胀 |
| **密度板（MDF）** | 造型门板、背板 | 表面平整，适合做造型与贴皮 |

- 商品页会写明**主材**与**辅材**（哪些部位用了颗粒板），不以"实木家具"笼统标注。
- **"实木家具"≠"全实木"**：行业惯例允许主材实木 ＋ 辅材人造板，我们的标注口径就是按这条走的。
  这类**主辅材标注差异不构成"描述不符"**，因此不按质量问题受理；
  但仍可按《退换货总则》走**无理由退货**（未使用、原包装配件齐全即可）。

## 环保等级

按 **GB 18580-2017** 的甲醛释放量分档，我们的内控比国标更严：

| 等级 | 甲醛释放量 | 我们用在哪 |
|---|---|---|
| E1（国标底线） | ≤ **0.124 mg/m³** | 不使用 |
| **E0**（企业内控） | ≤ **0.050 mg/m³** | 全线柜体与桌类 |
| **ENF**（无醛添加级） | ≤ **0.025 mg/m³** | 儿童家具、卧室系列 |

- **检测报告**：下单后可索取**同批次**报告，**7 个工作日内**发到下单邮箱。
- ⚠️ **不承诺"零甲醛"**。木材本身与胶黏剂都会有极微量释放，"零甲醛"是营销词，不是可检测的状态。
  任何承诺"零甲醛"的客服话术都是错的。

## 新家具的气味

- 正常情况：开封后**通风 7~15 天**，气味明显下降。
- 以下属于**正常现象**，不构成质量问题：木材本身的酸味、封边胶的轻微气味、抽屉内密闭空间气味偏重。
- 以下属于**该处理**的情况：刺鼻辣眼、持续 **30 天以上**不散、密闭房间内明显头晕 —— 按质量问题走《退换货总则》。

## 与保修的关系

- 环保等级**不属保修范围**：它是出厂性能指标，不是使用中会坏的东西。
- 板材**受潮膨胀、封边翘起**若因环境湿度长期 > 70% 或直接浸水导致，按《保修与维修》的"人为损坏/使用不当"处理（付费维修）。
- 板材**自然开裂**（非外力）在保修期内免费维修（家具主体保修 **2 年**）。
