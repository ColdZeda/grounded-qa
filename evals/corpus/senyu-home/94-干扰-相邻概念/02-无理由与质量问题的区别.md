# 无理由退货与质量问题退货的区别

> 帮助中心 · 现行有效 · 2026-01-05 更新。

## 两者的关键差别

| | 无理由退货 | 质量问题退货 |
|---|---|---|
| 前提 | 商品**没有毛病**，就是不想要了 | 商品**有缺陷**（破损/错发/色差/功能失效/开线变形） |
| 时间窗口 | 总则 **7 天**（美国 30 天 / 德国 14 天 / 日本 8 天） | **30 天**（各站一致） |
| 商品状态要求 | **未使用、不影响二次销售**、原包装齐全 | 无此要求，但要保留证据 |
| 运费 | 顾客承担（金卡前 3 次、美国 ≥$59 除外） | **商家承担** |
| 能否换货 | 能 | 能（退货/换货/部分退款三选一） |
| 能否部分退款 | **不能**，只能整单退 | **能**，轻微瑕疵可协商部分退款 |
| 证据要求 | 不需要 | **必须**照片或视频 |

## 选错了会怎样

- 明明是质量问题、却按"无理由"提交 → 运费会被算到顾客头上，而且**可能因为"已拆封"被拒收**。
- 明明是无理由、却谎称质量问题 → 仓库质检会推翻，**退回运费仍需顾客承担**，且可能影响账号信誉。

## 常见误判

1. **"色差严重"** —— 属于质量问题（前提是屏幕色差之外的**实物差异**）；
   **"和我想象的颜色不一样"** —— 属于无理由。
2. **"包装在运输中压瘪了，商品没事"** —— 不构成质量问题，可按无理由退，运费顾客承担。
3. **"用了两周觉得不好用"** —— 属于无理由，但**已使用** ⟹ 超过"不影响二次销售"判定，**通常不予退货**。
4. **"大件家具装好后发现颜色不喜欢"** —— 已安装即视为已使用，**不支持无理由**；
   但**德国站**的法定撤回权不受此限制（顾客承担拆装与逆向物流费用）。

## 一句话决策法

> 先问"东西**有没有毛病**"。
> 有 → **质量问题**，30 天，商家出运费，要拍照。
> 没有 → **无理由**，7 天（美国 30 / 德国 14 / 日本 8），要看是否未使用，运费多半你出。
