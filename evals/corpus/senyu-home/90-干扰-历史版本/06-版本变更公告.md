# 版本变更公告：2025-12-31 政策换版

> ⚠️ 本页为 2023 年版政策的换版公告存档，随旧版一并归档，仅供历史查询，不再适用。

## 公告正文

各位顾客、各位同事：

森屿家居对退换货、保修、运费与会员规则进行了统一修订，**新版政策自 2025-12-31 起生效**。自生效日起，**2023 年版各项政策整体废止**，不再适用于任何新提交的售后、报修与会员权益申请。

本次修订仅调整下列五项数值与等级设置，其余条款的表述与数值均保持不变。旧版存档仍保留在公司知识库中，供历史查询与争议追溯使用，但**不得作为现行答复依据**。

## 旧值与新值对照

| 项目 | 2023 年版（旧值，已废止） | 2025-12-31 起（新值） |
|---|---|---|
| 无理由退货期限（总则） | **15 个自然日** | **7 个自然日** |
| 家具主体保修期 | **1 年** | **2 年** |
| 美国站包邮门槛 | **$49** | **$59** |
| 美国站未达门槛的标准运费 | **$6.9** | **$7.9** |
| 信用卡 / PayPal 退款到账 | **7~10 个工作日** | **3~5 个工作日** |
| 会员等级数量 | **两级**（普通 / 银卡） | **三级**（普通 / 银卡 / 金卡） |
| 银卡门槛（年累计实付） | **$600** | **$500** |
| 金卡门槛（年累计实付） | 不设金卡 | **$1500** |

| 无理由退货运费补贴 | **无** | 金卡会员每自然年前 **3 次**补贴 |

## 本次未调整的项目

为避免误解，以下项目**新旧版一致**，不属于本次换版范围：质量问题退换仍为签收后 **30 个自然日**；电子件保修仍为 **1 年**；本地钱包与银行转账退款到账仍为 **7~15 个工作日**；德国站 €69、日本站 ¥8000、新加坡与马来西亚 S$80 的包邮门槛，以及各站未达门槛的运费均未变化；美国站与德国站仍为 DDP，日本、新加坡、马来西亚仍为 DDU；破损报障仍为 **48 小时**，丢件与少件错发仍为 **7 天**；会员积分单笔抵扣上限仍为 **20%**，积分有效期仍为 **12 个月**。

## 生效后的处理口径

1. 2025-12-31 及以后新提交的售后、报修与会员权益申请，一律按新版政策判定。
2. 客服与售后人员在答复顾客时，应以新版政策文档为唯一依据，**不得引用旧版数值**。
3. 发现旧版文档被误引用或误挂载到对外渠道的，应立即上报并下线。
4. 旧版文档仅保留在历史区，标注废止日期，检索命中后应先核对版本再作答。

以上调整自 2025-12-31 起执行。本公告所列新值在此后各版本中未再调整。

森屿家居 客户服务部
