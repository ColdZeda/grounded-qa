# 提问带图 · 图片素材生图提示词

> 状态：**当前有效** ｜ 建立于 2026-10-21
>
> **给谁用**：用户（拿任意文生图模型跑）／助手（核对真值）
>
> ⚠️ **这不是"测试数据"，是作品集的一部分**：评测、演示、面试都指着这几张图。
> 所以**不许出现**真实品牌、真实单号、真实地址姓名电话。

---

## 一、怎么用

1. 按下面 7 段提示词分别生成（或实拍，见每条的「优先」），
2. 按 **文件名** 存到 `repo\evals\fixtures\images\`，
3. 告诉我一声 —— 我会**打开每张图核对真实内容**，再按图写 `images.meta.yaml` 的真值
   （⚠️ 按图核对，**不是**照这里写的期望值填；文生图经常把字符画错）。

**所有图都要遵守的统一约束**（每条提示词里都重复写了）：

```
手机截图 / 随手拍风格；正常字号；常见无衬线字体（黑体 / 思源黑体一类）；
不要花体字、艺术字、超大标题、logo、人脸、真实品牌、真实地址电话。
```

> 📌 **为什么禁止花体字和超大标题**：评测比的是"模型能不能认对字"，
> 不是"能不能认出艺术字"。字太花会让人看不出是**识别**失败还是**图片本身**不可读，
> 那样量出来的数字没有代表性。

## 二、放回后的检查清单（我会跑）

| # | 检查 | 不通过会怎样 |
|---|---|---|
| 1 | 7 个文件名与上表**完全一致** | 评测直接报"缺图"，不许静默按 0 分算 |
| 2 | 每张图能打开、格式是 png/jpeg、单张 < 200 KB | 仓库体积、以及"上传上限 3 MB"那条路径测不到 |
| 3 | 图里的字符与 `images.meta.yaml` 的真值一致（**按图核对**） | 真值与图不一致 = 评测在测错的东西 |
| 4 | 图里的单号能对上 `app/db/seed.py` 的订单（P1=SF10001 / P2=SF10002） | 不一致就**改 seed 去对齐图**，不要重新生成图 |
